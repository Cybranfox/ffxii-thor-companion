FFXII Thor Companion - game script installer

These files were put here by the FFXII Companion app.

First time (once): install the companion's small loader into the game.
  1. In GameNative, open FINAL FANTASY XII THE ZODIAC AGE > Options > Open container.
  2. In the file manager, open D: > FFXII_companion > install and double-tap install.cmd.
  3. result.txt in this folder says INSTALLED (or what to fix). Exit the container and play.

Updates: just install the new companion APK. At the next game start the loader checks the new game script's
signature and runs it. You only run install.cmd again if a release note asks you to.

To remove it, double-tap uninstall.cmd the same way, then uninstall the app.
Full guide: https://github.com/Cybranfox/ffxii-thor-companion/blob/main/docs/INSTALL.md
